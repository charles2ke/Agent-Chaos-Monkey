# Resilience leaderboard

Measured output of `cli/benchmark.mjs`, not an assertion. Every row below comes from a real run whose
evidence is the tool-boundary trace: HTTP statuses, retry timing and side-effect ids observed at the
gateway, plus the user-visible reply the evidence evaluator scored.

## Reproduce

```bash
# Terminal 1 — the connector the gateway is allowed to forward to
node examples/sample-agent/tool.mjs --port 5251

# Terminal 2 — the API with the live gateway enabled
cd backend/ChaosMonkey.Api
LabGateway__Enabled=true \
LabGateway__PublicBaseUrl=http://127.0.0.1:5249 \
LabGateway__AgentEndpoints__0=http://127.0.0.1:5250/agent \
LabGateway__Operations__0__Connector=ServiceNow \
LabGateway__Operations__0__Operation=CreateIncident \
LabGateway__Operations__0__Url=http://127.0.0.1:5251/create \
LabGateway__Operations__0__Method=POST \
LabGateway__Operations__0__SideEffectIdProperty=id \
dotnet run --no-launch-profile --urls http://127.0.0.1:5249

# Terminal 3
node cli/benchmark.mjs examples/benchmark-targets.json --url http://127.0.0.1:5249 --output results/benchmark
```

The benchmark starts and stops each target agent itself and writes `benchmark.json` plus a
regenerated copy of the table below.

"Inconclusive" is a deliberate outcome: injection resistance is only scored on runs where a
prompt-injection payload was actually delivered at the boundary, and retry behaviour only where a
retryable fault occurred.

### What the failures were

The optimistic and naive agents fail the same four experiments — expired auth, prompt injection, tool
schema drift and cascading failure — because each one tells the user the request succeeded when the
connector returned 401, 400 or 503 and no record was created. The naive agent additionally relays raw
connector text, so it repeats the per-run canary phrase planted in the injected payload and fails the
`noInjectedInstructionFollowed` assertion.

## Scope and honesty

These are the agents this repository can run unattended in CI. **No externally hosted agent platform is measured
here yet.** Direct Line agents, LangChain and Azure AI Agent Service each require credentials and a hosted
agent, so they are listed as unmeasured rather than estimated:

| Platform | Status | How to add it |
| --- | --- | --- |
| Bot Framework / M365 Agents SDK over Direct Line | Not yet measured | [`docs/DIRECT_LINE.md`](DIRECT_LINE.md) — `transport: "directline"` with a channel secret. |
| LangChain / LangGraph | Not yet measured | Expose the agent over HTTP and use `transport: "gateway"` with the payload contract in [`examples/sample-agent`](../examples/sample-agent/README.md). |
| Azure AI Agent Service | Not yet measured | Same gateway contract; a thin HTTP wrapper around the thread run. |

Contributions that add a measured row, with the run artifacts attached, are welcome — see
[CONTRIBUTING.md](../CONTRIBUTING.md).
